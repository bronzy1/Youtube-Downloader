# YouTube Downloader App

This is a **YouTube Downloader Bot** built using **Streamlit** and **pytube** to download YouTube videos and audio. It offers a simple interface where users can paste the video URL and choose to download either the video or audio.

## Features

- **Password Protection**: The app requires a password to access the download features.
- **Download Audio**: Users can download the audio of a YouTube video.
- **Download Video**: Users can download the video in the highest resolution.
- **Easy to Use**: Simple interface with a clear option to either download the video or audio.
